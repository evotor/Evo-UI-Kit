# AGENTS.md - библиотека компонентов `@evotor-dev/ui-kit`

Знание о коде живёт здесь, в дереве репозитория: его читают и человек, и агент, и оно уезжает вместе с репозиторием.
Знание о маршруте конкретной задачи в этот файл не попадает.

Это публичная библиотека компонентов, которую подключают фронты ЭвоБонуса и Сбер Лояльности.
Правка здесь уезжает не в один продукт, а во все сразу, поэтому цена ошибки выше, чем в приложении.

## Стек

| Что | Чем | Где смотреть |
| --- | --- | --- |
| Фреймворк | Angular 17 | библиотека - `projects/evo-ui-kit` |
| Витрина | Storybook | `npm run storybook`, опубликована на evotor.github.io/Evo-UI-Kit |
| Тесты | Karma и Jasmine | `npm test`, в CI - `npm run test:ci` |
| Линт | ESLint и stylelint | `npm run lint` |

## Коммиты и релизы

Формат сообщения - Angular Conventional Commits, и это не пожелание: сообщение проверяет `commitlint` (`commitlint.config.js`).
Тип коммита управляет релизом, поэтому `feat` и `fix` в основной ветке выпускают версию, а `docs`, `test` и `chore` - нет.
Каналы поставки (`@latest`, `@beta`, поддержка старых мажорных версий) и порядок публикации описаны в `CONTRIBUTING.md`, дублировать это здесь не нужно.

## Проверки

Единой цели `make` в репозитории нет, проверки запускаются скриптами npm: `npm run lint`, `npm test`, `npm run build`.

## Решения

Развёрнутые архитектурные и процессные решения - с причиной, отвергнутыми альтернативами и последствиями - живут в `docs/decisions/<класс>/<slug>.md`, по файлу на решение.
Конвенции выше - выжимка правил; когда нужно понять, почему правило именно такое, идти туда.
